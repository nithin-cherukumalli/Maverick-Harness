Route: New + No AI + Not distributed + Trust boundary → modular-architecture → engineering-mindset → production-readiness → security-engineering (trust/isolation).

Cognitive Job

Given a code change produced by a coding agent, independently verify it against hidden tests, adversarial cases, and evidence integrity — producing a binary VERDICT (VERIFIED exit 0 / NOT PROVEN exit non-zero). The harness itself performs no LLM reasoning; it is a deterministic control layer.

DimensionSpecification
InputsCode change (git diff/commit), task spec (from Genesis CLI), hidden QA tests (outside agent reach), trap scenarios
OutputsVERDICT (VERIFIED exit 0 / NOT PROVEN exit non-zero), evidence bundle (SHA, env, timestamp, exit code, result)
Reasoning depthDeterministic — test execution, mutation testing, evidence checking. No probabilistic reasoning inside the harness.
Autonomy levelFully autonomous for verification. Human required for decisions, approvals, escalation after 3 failed repairs.
Human involvementDecision-making (proposals vs decisions), approval gates for high-risk changes, escalation after 3 failed repair attempts
Failure toleranceBounded repair (max 3 attempts, then BLOCKED → HUMAN). Every failure logged.
Trust boundariesCoding agent: UNTRUSTED. Verifier: TRUSTED. Hidden QA: OUTSIDE agent reach. Genesis: UNMODIFIED (CLI only, version pinned).
